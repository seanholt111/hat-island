# Hat Island Explorer

Interactive pan & zoom of a cinematic 3D-style render of Hat Island (Gedney Island), Washington.

## Phone
Open the GitHub Pages link in Safari/Chrome. Drag to pan, pinch to zoom. Use + / − / home buttons if you prefer.

## Local
Open `index.html` next to `hat-island.png` (needs a real web host or Pages — iPhone Files Preview will not work).
